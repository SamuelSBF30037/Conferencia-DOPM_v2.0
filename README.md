# Conferência DOPM

**Versão:** 2.0

**Descrição**
Executa os 4 scripts de conferência do DOPM e gera um único relatório unificado por tópicos.

**Sobre**
Ao contrário dos scripts avulsos anteriores, esta é uma extensão completa que automatiza a conferência de dados nos sistemas SEI e SISP para o contexto do DOPM.
